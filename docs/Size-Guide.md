# Loose-fit size guide

Malik confirmed BAETEE T-shirts are loose fit. The user authorised a measurement guide first while the actual numeric chart is pending. `components/store/SizeGuide.jsx` is shared by PDP and quick-shopping size selectors.

To complete the numeric chart, obtain confirmed laid-flat chest width, body length and shoulder width for XS, S, M, L, XL and XXL, including units and any supplier tolerance. Do not derive values from a generic brand chart. Until then, the UI clearly states measurements are awaiting confirmation.
